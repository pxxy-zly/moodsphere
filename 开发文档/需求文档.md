# 心境气象站（MoodSphere）需求文档

## 1. 项目概述

### 1.1 项目名称

**中文名称**：心境气象站
**英文名称**：MoodSphere
**项目简称**：MS

### 1.2 项目背景

在快节奏生活中，用户的情绪常常难以被及时表达、记录和理解。传统日记和情绪记录工具通常停留在文字层面，缺乏可视化反馈与沉浸式体验，难以形成持续使用动力。

本项目尝试通过 **AI 情绪识别 + 天气意象映射 + 数字可视化** 的方式，将用户抽象的情绪状态转化为可感知的“情绪天气”，帮助用户更自然地记录情绪、观察变化，并在匿名前提下感知群体情绪氛围。

### 1.3 项目目标

构建一套面向个人情绪记录与群体情绪可视化的全栈应用系统，实现：

1. 用户可通过文字、语音、图片记录当下情绪
2. 系统通过 AI 对输入内容进行情绪分析
3. 将情绪分析结果映射为动态天气景观
4. 用户可查看个人情绪天气、历史快照和趋势报告
5. 匿名情绪数据可投影到“情绪星球”中，形成群体情绪可视化展示

### 1.4 项目定位

一款基于 AI 情绪识别与数字气象可视化的全栈情绪交互平台。

### 1.5 一句话描述

**让情绪像天气一样被看见。**

## 4. 业务流程概述

### 4.1 用户登录流程

1. 用户打开应用
2. 系统判断本地是否存在有效 token
3. 若无 token，则进入登录页
4. 用户通过微信一键登录
5. 后端根据微信身份查询或自动创建系统用户
6. 初始化业务用户资料和用户配置
7. 返回登录 token
8. 前端保存 token 并跳转首页

### 4.2 情绪记录流程

1. 用户进入记录页
2. 输入文字，或上传语音/图片
3. 可选择情绪标签、场景标签、情绪强度
4. 提交记录
5. 后端保存原始记录
6. 触发 AI 分析
7. 输出情绪结构化结果与向量
8. 映射为天气参数
9. 返回分析结果与天气数据
10. 前端展示情绪天气与结果页

### 4.3 天气展示流程

1. 用户进入首页
2. 后端读取当前最新天气映射结果或当天快照
3. 返回天气类型、云量、风速、色温、粒子样式等参数
4. 前端根据参数渲染动态天气场景

### 4.4 报告生成流程

1. 系统按日/周/月聚合用户情绪记录
2. 生成趋势统计和主导情绪分析
3. AI 生成摘要
4. 存储报告结果
5. 用户在报告页查看

### 4.5 星球投影流程

1. 用户开启匿名投影
2. 系统对公开记录进行脱敏处理
3. 聚合区域情绪数据
4. 投影到星球可视化模块
5. 用户查看区域情绪分布与热力变化

## 7. 非功能需求

### 7.1 性能要求

* 登录接口响应时间：正常情况下小于 2 秒
* 情绪分析接口：正常情况下小于 5 秒
* 首页天气展示：页面首屏小于 3 秒
* 报告列表查询：小于 2 秒

### 7.2 安全要求

* 所有用户接口必须基于 token 鉴权
* 微信身份信息不得明文暴露给前端
* 风险记录后台访问需做权限控制
* 用户原始情绪内容需限制后台查看权限
* 位置信息需脱敏处理后用于星球展示

### 7.3 可扩展性要求

* 支持后续增加手机号绑定
* 支持后续增加游客模式
* 支持更换 AI 模型供应商
* 支持扩展新的情绪维度
* 支持扩展新的天气映射规则

### 7.4 可维护性要求

* 按模块拆分业务代码
* 统一返回体格式
* 统一异常处理
* 统一日志记录
* 核心服务保留调试信息与链路追踪
