# MoodSphere Station 管理端（MSS-ui-admin）

## 项目简介

心境气象站（MoodSphere Station，MSS）是一款基于 Spring Boot 3、Vue 3 与 UniApp 构建的全栈实验型应用。项目通过文本、语音、图片等多模态方式采集用户情绪输入，结合 AI 大模型进行语义分析与情绪向量提取，并将结果映射为动态天气参数，形成个性化的“情绪天气”数字景观。系统同时支持基于 Three.js 的群体情绪数字地球展示，以可视化方式呈现匿名群体情绪的空间分布与动态变化，适用于心理健康辅助、情绪记录、社交互动及数字艺术展示等场景。

本仓库为 MSS 的 PC 管理端，基于若依前端初始代码扩展，主要用于：

- 平台用户、权限与配置管理
- 情绪数据与分析结果管理
- 群体情绪大盘与运营可视化
- 系统监控、日志审计与运维支撑

## 管理端定位

管理端聚焦“配置、运营、审计、观测”四类能力，服务对象为运营、产品与平台管理员：

- 配置中台：管理标签、映射规则、提示词模板与展示参数
- 运营中台：查看用户增长、记录活跃、情绪分布与趋势变化
- 风控中台：处理风险识别结果、预警记录与人工复核
- 可视化中台：查看群体情绪大盘与星球投影统计

## 技术栈

- Vue 3（后续演进）
- Vue CLI / 工程化构建体系
- Element UI
- Axios

## 页面域建议

- 用户与权限域：账号、角色、菜单、数据权限
- 情绪记录域：记录查询、标签统计、场景分析
- AI 分析域：模型调用日志、成功率、成本监控
- 天气映射域：映射规则、模板配置、参数调优
- 星球运营域：区域热力、时间切片、投影比率
- 报告中心域：日报/周报/月报生成与导出
- 风险治理域：风险等级、处置流程、审核备注
- 系统运维域：任务调度、缓存监控、接口审计

## 与后端模块协同

- `system-user`：登录鉴权、账号安全、权限校验
- `mood-config`：标签与规则配置，驱动前台表现
- `mood-stat`：运营统计与指标聚合
- `mood-risk`：风险数据回流与人工处置
- `mood-globe`：群体情绪投影与可视化数据源
- `mood-report`：报告生成、查看、导出能力

## 本地开发

```bash
npm install
npm run dev
```

默认访问地址：`http://localhost:80`

## 构建发布

```bash
npm run build:stage
npm run build:prod
```
